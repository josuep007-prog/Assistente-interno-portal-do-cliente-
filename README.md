# Assistente interno do Portal do Cliente

Extensão de navegador (em construção) para ajudar analistas e gestores a usar e
controlar o Onvio Portal do Cliente: solicitações de serviço e documentos.

## Conteúdo

* `mapeamento/portal-do-cliente.md`: mapa das telas, regras e dores do portal,
  com as ideias de funções da extensão.
* `mapeamento/capturar-mapa-onvio.js`: script para colar no console do Chrome e
  capturar a estrutura das telas e as APIs do portal, sem dados de clientes.
